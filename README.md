# GradeIQ — Student Performance Predictor

A full-stack machine learning web app that predicts whether a student will **pass or fail** their final exam based on 38 features including study habits, family background, term grades, and lifestyle factors.

## Demo

![GradeIQ Preview](https://i.imgur.com/placeholder.png)

## Tech Stack

| Layer | Technology |
|---|---|
| ML Model | Random Forest (scikit-learn, GridSearchCV) |
| Resampling | SMOTE (imbalanced-learn) |
| Backend | Flask (Python 3.13) |
| Frontend | Vanilla HTML/CSS/JS — no framework |
| Dataset | UCI Student Performance (649 students) |

## Model Performance

| Metric | Score |
|---|---|
| Accuracy | 86.2% |
| ROC-AUC | 0.954 |
| F1 Score | 0.905 |
| Precision | 0.896 |
| Recall | 0.915 |

## Features

- **38-feature input** — 33 original UCI features + 5 engineered (study/freetime ratio, parental support score, alcohol index, social risk, aspiration flag)
- **SMOTE balancing** — handles the 72/28 pass/fail class imbalance in training
- **GridSearchCV tuning** — 144 hyperparameter combinations, 5-fold stratified CV
- **Explainable predictions** — plain-English risk/strength factors for each prediction
- **SVG probability circle** — animated arc showing confidence level
- **Dark mode UI** — 3-panel app shell (sidebar + form + result panel)

## Setup

```bash
# Install dependencies
pip install -r requirements.txt

# Train the model (required before running the app)
python train_model.py

# Start the Flask server
python app.py
```

Then open `http://127.0.0.1:5000`.

## API

| Method | Route | Description |
|---|---|---|
| GET | `/` | Web UI |
| POST | `/predict` | Returns prediction + probability + insights |
| GET | `/model-stats` | Model metrics + feature importances |

## Dataset

Based on the [UCI Student Performance Dataset](https://archive.ics.uci.edu/ml/datasets/Student+Performance) by P. Cortez and A. Silva (2008). The dataset covers students in Portuguese secondary schools with 33 attributes covering demographics, social factors, and academic performance.
